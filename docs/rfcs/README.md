# RFCs

Non-trivial features that touch the public API, add a crate, or change auth/XRPC semantics go through a lightweight RFC process.

## Process

1. Copy `0000-template.md` to `NNNN-title.md` (next available number).
2. Fill in the template sections.
3. Open a PR with the RFC.
4. Discussion happens on the PR.
5. Once approved, the RFC is merged and implementation begins.
